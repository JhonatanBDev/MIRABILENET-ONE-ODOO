Odoo sigue el modo claro u oscuro del navegador o del sistema, sin que cada usuario tenga que
activarlo.

- Usa el módulo de OCA `web_dark_mode` para la parte interna de Odoo. Este módulo enciende en
  todos los usuarios internos su opción «modo oscuro según el dispositivo»: a los que ya existen
  al instalarlo y, como valor por defecto, a los que se creen después.
- Oscurece la pantalla de ingreso, la de registro y la de cambio de contraseña cuando el
  navegador está en oscuro. El resto del sitio web público no cambia.
